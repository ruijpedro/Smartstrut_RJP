# SmartStruct_RJP V35 — Editor Estrutural 2D + Pórticos

Novo editor comum para:
- nós 2D;
- barras;
- apoios livre/articulado/móvel/encastrado;
- cargas nodais;
- geometria paramétrica;
- visualização SVG;
- equilíbrio global e resultados preliminares por barra.

O objetivo é convergir Vigas, Pórticos e Treliças para um modelo estrutural comum.
Nesta fase o solver do editor é preliminar; os módulos especializados V34 continuam disponíveis.
