# SmartStruct_RJP V102 — Estruturas Metálicas

Novo módulo de pré-dimensionamento e verificação preliminar de estruturas metálicas.

Inclui:
- propriedades manuais de perfis e material;
- resistências N, My, Mz e V;
- encurvadura global nos dois eixos com curvas parametrizadas;
- triagem de ligação aparafusada;
- quantificação de aço;
- checklist explícito das verificações ainda necessárias;
- persistência local em `smartstruct:steel-structures`;
- acesso no menu e no Dashboard.

Nota: módulo de triagem/estudo prévio. Não substitui a classificação da secção, encurvadura lateral-torcional, interação regulamentar completa, ligações detalhadas, fogo, fadiga ou requisitos do Anexo Nacional aplicável.
