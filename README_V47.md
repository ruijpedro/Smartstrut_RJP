# SmartStruct_RJP V47 — Projeto Hidráulico Predial

Evolução do módulo Hidráulica:
- projeto por divisões e pisos;
- aparelhos por WC/cozinha/divisão;
- acumulação automática de caudais;
- pré-dimensionamento automático de água;
- sugestão de DN, velocidade e perda de carga;
- pré-dimensionamento de esgoto por Manning a meia secção;
- respeito pelo maior DN mínimo associado aos aparelhos na base;
- esquema conceptual automático da rede;
- layout responsivo.

Base regulamentar implementada na interface:
- DR 23/95 arts. 89–94 (água predial);
- arts. 208–215 (descargas prediais);
- arts. 229–231 (tubos de queda);
- arts. 244–249 (coletores).

Nota: curvas/tabelas gráficas dos Anexos IV, V, XIV–XVIII requerem validação/transcrição
exata antes de o resultado ser tratado como dimensionamento regulamentar definitivo.
