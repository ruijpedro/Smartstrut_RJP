# SmartStruct_RJP V88 — Materiais + base BIM

- Biblioteca Técnica ampliada com Agregados e Materiais Granulares.
- Fichas técnicas pesquisáveis para areias, britas, ABGE, tout-venant, drenantes, reciclados, leves, balastro, rachão e enrocamento.
- Terminologia PT-PT.
- Valores comerciais/normativos não são apresentados como universais; a especificação do projeto prevalece.
- Nova estrutura interna `SmartStruct-BIM/0.1` para objetos de engenharia: disciplina, tipo, geometria, material, propriedades e resultados de cálculo.
- A estrutura BIM é preparatória e não é ainda um exportador IFC.
