# SmartStruct_RJP V72 — Planta XY e ligação ao perfil

Versão de consolidação do módulo viário para início de testes em projetos.

## Novo
- eixo viário editável em coordenadas XY locais;
- vértices do eixo editáveis;
- comprimento automático por segmentos;
- colocação de elementos de drenagem diretamente na planta;
- projeção automática de um clique XY sobre o eixo;
- conversão automática XY → PK + afastamento;
- conversão automática PK + afastamento → XY;
- elementos parametrizados por PK/offset;
- ao alterar o eixo, os elementos mantêm a referência longitudinal e reposicionam-se;
- associação visual com rasante/perfil longitudinal;
- tipos: caixa, sumidouro, valeta, aqueduto e descarga.

## Mantém
Todo o conteúdo V71 e anteriores:
- traçado;
- rasante;
- secções;
- visibilidade;
- terraplenagens;
- diagrama de massas;
- drenagem superficial;
- valetas;
- aquedutos;
- bacias;
- perfil longitudinal de coletores;
- planta de drenagem.

## Estado
Esta versão fecha a atual fase de evolução do módulo viário para permitir testes em projetos reais.
Ferramenta de apoio/pre-dimensionamento; não substitui levantamento topográfico, projeto regulamentar, CAD/GIS ou modelo hidráulico completo.
