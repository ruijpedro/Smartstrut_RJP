# SmartStruct_RJP 79.0 — Mapa Global de Aço

## Structural Project PRO
Novo separador `Mapa de aço` com:
- agregação preliminar das armaduras de vigas, pilares e sapatas;
- marcas individuais de varões/estribos;
- notação nØ e Ø//espaçamento;
- quantidade;
- comprimento unitário;
- comprimento total;
- peso por marca;
- peso total e subtotal por tipo de elemento;
- gráfico-resumo por Vigas / Pilares / Sapatas;
- exportação CSV compatível com Excel;
- peso total também incluído no resumo do projeto.

## Metodologia atual
O mapa usa os envelopes já existentes no Structural Project PRO. Para vigas e pilares ainda usa secções de referência do modelo global e estimativas de comprimentos adicionais/estribos. As sapatas usam os resultados do módulo de fundações e a seleção automática de armadura distribuída.

## Limitações
Este mapa é de quantificação/pre-dimensionamento e não substitui uma lista de corte de execução validada. A evolução seguinte deve ligar diretamente as armaduras pormenorizadas de cada elemento do projeto, respetivas ancoragens, emendas, cortes e comprimentos reais.
