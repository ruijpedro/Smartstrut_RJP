# SmartStruct_RJP — V84

## Estudo Prévio Integrado
- O separador Estudo Prévio passa a recolher dados reais guardados pelos módulos.
- Structural Project PRO: projeto, geometria base e materiais guardados.
- LSF: snapshot automático de geometria, materiais, ações, utilizações e quantificação.
- Hidráulica: rede pública guardada, número de nós/troços e comprimento modelado.
- Exportação JSON do estudo integrado e impressão/PDF.
- Dados inexistentes são assinalados; não são inventados.

Próxima profundidade: persistência normalizada para geotecnia, contenção, vias, vigas/pilares/lajes/sapatas e geração de memória de cálculo por capítulos.
