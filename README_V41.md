# SmartStruct_RJP V41 — Solver Matricial 2D Real

- solver matricial de pórticos 2D com 3 GDL por nó;
- montagem automática da matriz global de rigidez;
- condições de apoio por GDL;
- cargas nodais Fx, Fy e M;
- deslocamentos ux, uy e rz;
- reações nos apoios;
- esforços locais N, V e M nas extremidades das barras;
- deformada amplificada;
- diagramas gráficos N / V / M por barra;
- edição de E, A e I por elemento.

Esta versão liga o Engineering Core V40 ao editor estrutural.
