# SmartStruct_RJP V81

- Biblioteca SVG profissional inicial para o editor hidráulico, substituindo círculos/letras por símbolos técnicos próprios e escaláveis.
- Base gráfica inspirada em convenções de documentação técnica, sem incorporar/copiar a biblioteca normativa protegida.
- Novo separador **Estruturas LSF** para Light Steel Framing.
- V81 LSF inclui parede paramétrica, modulação 400/600 mm, perfis C/U, espessura, quantificação e desenho responsivo.
- O cálculo resistente LSF completo fica explicitamente marcado como evolução; deverá usar EN 1993-1-3 e respetivo Anexo Nacional aplicável.
