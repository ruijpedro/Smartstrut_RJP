# SmartStruct_RJP V32 — Contenção aprofundada

Desenvolvimento funcional de:
- Muro de betão armado
- Muro de gravidade
- Gabiões
- Muro de Berlim
- Cortina de estacas
- Terra reforçada

Inclui:
- motores de cálculo preliminar separados;
- impulsos de Rankine reutilizáveis;
- verificações básicas de deslizamento, derrubamento e tensões;
- desenhos SVG paramétricos;
- interface de comparação de soluções.

Nota: ferramenta de apoio académico e análise preliminar. Não substitui projeto/verificação regulamentar integral.
