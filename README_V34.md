# SmartStruct_RJP V34 — Estruturas PRO

Evolução dos quatro módulos estruturais principais.

## Vigas
- mais tipos de apoio;
- momentos de encastramento;
- armadura mínima/requerida;
- tensão de corte preliminar;
- relação vão/altura;
- verificação simples de flecha.

## Pilares
- comprimento efetivo;
- esbelteza nos dois eixos;
- efeitos de 2.ª ordem aproximados;
- interação N-Mx-My;
- As mínima/máxima/requerida.

## Lajes
- simples ou contínua;
- 1D/2D;
- momentos positivos e negativos;
- As mínima e requerida;
- indicador de deformabilidade.

## Treliças
- Pratt, Howe, Warren;
- tensões aproximadas;
- rigidez axial;
- flecha aproximada;
- índice geométrico de material.

Também preparada a integração do pacote ic_launcher para Android quando a estrutura android/res está presente.
