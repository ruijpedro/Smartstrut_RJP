# SmartStruct_RJP V63 AUTO

Evolução do Modelo de Edifício V62.

- análise matricial automática;
- pré-dimensionamento individual de pilares de base;
- pré-dimensionamento de vigas;
- otimização iterativa das sapatas;

- cadeia edifício → esforços → secções → fundações.

As regras AUTO de secções são heurísticas de pré-dimensionamento e não substituem verificações EC2/EC7.
