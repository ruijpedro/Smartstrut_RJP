# SmartStruct_RJP V33 — Estruturas aprofundadas

Evolução funcional dos módulos:
- Vigas: tipos de apoio, cargas distribuídas/pontuais, reações, V, M, flecha e As preliminar.
- Pilares: compressão + flexão biaxial, esbelteza, tensões e armadura preliminar.
- Lajes: comportamento uni/bidirecional, ações, momentos e armaduras por metro.
- Treliças: Pratt, Howe e Warren, geometria, reações e esforços aproximados.

Todos os módulos incluem desenho SVG paramétrico e interface responsiva.
Ferramenta de apoio académico e pré-dimensionamento; não substitui verificação regulamentar integral.
