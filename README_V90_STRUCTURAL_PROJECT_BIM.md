# SmartStruct_RJP V90 — Structural Project ↔ BIM

- Ligação direta do Structural Project PRO ao modelo BIM interno.
- IDs BIM persistentes derivados dos IDs dos elementos/nós estruturais.
- Vigas, pilares e sapatas recebem geometria, material, resultados dos envelopes e armadura preliminar.
- Atualização automática do BIM quando o projeto/cálculo muda e botão manual **Atualizar BIM**.
- SmartStruct-BIM atualizado para schema 0.3.
- O modelo de cálculo continua 2D; a representação BIM não constitui análise FEM 3D.
