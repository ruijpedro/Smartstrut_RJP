# SmartStruct_RJP — V83 Estudo Prévio

Nova área transversal **Estudo Prévio** para organizar o desenvolvimento técnico por especialidade.

- Estruturas
- Estruturas LSF
- Geotecnia
- Contenção e estabilização
- Hidráulica e drenagem
- Infraestruturas viárias

Cada especialidade mostra base normativa, conteúdo mínimo, estado (calculado / verificar / em falta), nível de desenvolvimento e saída Imprimir/PDF pelo browser.

O objetivo é transformar progressivamente os cálculos existentes numa memória técnica preliminar rastreável, sem apresentar aproximações como verificações regulamentares finais.
