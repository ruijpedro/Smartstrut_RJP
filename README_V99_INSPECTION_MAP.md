# SmartStruct_RJP V99 — Ficha de Inspeção / Mapa de Patologias

- Importação de imagem como base gráfica: planta, alçado ou fotografia.
- Marcação de patologias diretamente sobre a base importada.
- Associação opcional de cada registo a elemento BIM/openBIM.
- Persistência local da base apenas quando a imagem é suficientemente pequena para localStorage; imagens maiores permanecem disponíveis na sessão.
- Geração por impressão/PDF de Ficha de Inspeção com identificação do edifício, mapa, gravidade e tabela de anomalias.
- Mantém o alçado esquemático quando não existe imagem importada.
- Ferramenta de apoio a inspeção/estudo preliminar; não substitui levantamento medido, diagnóstico, ensaios ou verificações regulamentares.
