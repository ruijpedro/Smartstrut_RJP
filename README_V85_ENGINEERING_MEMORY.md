# SmartStruct_RJP — V85

## Estudo Prévio — Memória de Engenharia Integrada
- Estudo Prévio passa a mostrar evidência real recolhida dos módulos persistentes.
- Painel global de resultados disponíveis, verificações a aprofundar e ligações/dados em falta.
- Objetivo técnico específico por especialidade.
- Structural Project, LSF e rede hidráulica alimentam automaticamente a memória.
- Geotecnia, Contenção e Vias são explicitamente identificadas como próximas integrações persistentes, sem inventar resultados.
- Exportação JSON inclui identificação do estudo, resumo de estados, observações e dados integrados.
- Bloco de decisão preliminar: solução, condicionantes e próxima fase.

Nota: a aplicação continua a distinguir pré-dimensionamento de verificação regulamentar final.
