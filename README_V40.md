# SmartStruct_RJP V40 — Engineering Core

Aprofundamento técnico da base:
- solver matricial 2D de pórticos com 3 GDL por nó;
- reações e esforços locais nas extremidades das barras;
- arquitetura para diagramas N/V/M e deformada;
- combinações ELU/ELS por casos de carga;
- dimensionamento preliminar de vigas BA, corte, pilares e lajes;
- geotecnia: tensões efetivas, consolidação e coeficientes de impulso;
- modelo persistente de projeto e registos de cálculo;
- núcleo comum preparado para ligar Estruturas, Fundações, Contenção e Relatórios.

Nota: os cálculos permanecem ferramenta de apoio/pré-dimensionamento e devem ser validados antes de uso em projeto.
