# SmartStruct_RJP V61 — Pórtico → Fundação

Integração do solver matricial V57 com os motores de pilares e fundações.

Fluxo:
Pórtico 2D → reação do apoio selecionado → N/H/M → pilar → amplificação de 2.ª ordem → sapata.

Inclui modelo de dois pisos, cargas verticais e horizontal editáveis, seleção da fundação esquerda/direita e resultados automáticos de pilar, terreno, estabilidade, punçoamento e armaduras.
