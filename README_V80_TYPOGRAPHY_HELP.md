# SmartStruct_RJP 80.0 — Tipografia + Ajuda

## Tipografia
- unificada em toda a aplicação com a mesma família da interface;
- removidas sombras de texto;
- removidos contornos/strokes das etiquetas SVG;
- etiquetas Ø continuam com cor funcional, mas sem efeito desenhado;
- títulos, cartões, botões, inputs e desenhos técnicos usam a mesma base tipográfica;
- mantém legibilidade em telemóvel/tablet/desktop.

## Ajuda / Como operar
Novo módulo no menu:
`Ferramentas → Ajuda · Como operar`

Inclui:
- Começar aqui;
- fluxo geral;
- Structural Project PRO;
- Vigas, Pilares, Lajes, Sapatas;
- Pórticos/Treliças;
- Hidráulica;
- Infraestruturas Viárias;
- Geotecnia/Contenção;
- símbolos principais;
- interpretação de resultados;
- pesquisa rápida.

O manual foi atualizado com base no fluxo atual da aplicação e na evolução funcional até ao mapa de aço.
